# Hephaestus 시연 영상 대본

- 목표 길이: 약 2분 10초 (말하는 속도 기준 분당 약 300음절)
- 말투: 원고를 읽지 말고 심사위원 앞에서 직접 시연하듯이. `/`는 짧게 쉬기, **굵은 글씨**는 살짝 힘주기.
- 녹음: 장면마다 파일 하나씩 (`E01_오프닝.m4a` …). 틀리면 그 장면만 다시 녹음.
- 범위: 구현·검증된 기능만 넣었다 (정비소 감지, 출차 시 기록 질문, 주행거리 자동 기록, 교체 알림, 차량 신호 기반 질문, 내연기관·전기차 모드). F5 이력 내보내기(QR)는 미구현이라 넣지 않았다.
- 화면: 에뮬레이터 `emulator-5556` 녹화. 진행은 README 9장 "데모 순서"를 따른다.

## 녹화 메모

### 사전 준비 (녹화 전에 한 번)

1. 앱 데이터 초기화가 필요하면 `adb -s emulator-5556 shell pm clear --user 10 com.zigae.hephaestus` (Pleos 에뮬레이터의 운전자 사용자는 10번이라 `--user 10`이 없으면 "Success"만 찍히고 데이터가 남는다) → 앱 실행 → 차종 선택 화면에서 **[내연기관]** (E03에서 엔진오일·필터 칩을 눌러야 하므로 내연기관으로 시작한다. 전기차 전환은 E06에서).
2. 설정 > 정비소에 머문 시간 **[바로]**, 설정 > 개발용 "+50,000km".
3. E04 숫자를 맞추기 위해 소모품 탭 > 타이어 위치 교환 > [다른 주행거리로] → −1,000, −100 → **48,900km**에 기록. (내연기관 주기 10,000km → +10,000km 뒤 1,100km 지남). E03에서 기록한 엔진오일·필터(주기 7,000km)도 같이 "3,000km 지남"이 되어 알림이 2개 뜬다. 대본상 문제 없음.
4. 보기 좋게 2~3개 항목을 "지금 교체했어요"로 더 입력해 두면 E02 홈이 "급한 항목 없음 + 다음 교체 행"으로 보인다.
5. 기어는 Virtual Console `PUT /vehicle/gear?gear=Park|Drive`. 하트비트 루프가 돌고 있어야 한다(README 9장).

- 에뮬레이터 `emulator-5556` + Virtual Console `:8089`(하트비트 필요). 녹화 중엔 이 에뮬레이터 1대만 켠다.
- 터치 위치 표시: `adb -s emulator-5556 shell settings put system show_touches 1`
- 에뮬레이터 주행거리는 항상 0.0 → 설정 > 데모 "+50,000km"로 먼저 맞춘다. "시흥 오토 카센터"는 데모 목적지 이름이다(설정 > 데모 "현재 위치 카센터를 목적지로").
- 기록 질문 장면(E03)은 같은 곳에서 6시간 안에 다시 묻지 않으므로, 다시 찍을 땐 앱 데이터를 지우거나(위 사전 준비 1부터 다시) 설정 > 개발용 "방문 질문 바로 만들기"(쿨다운 무시, 데모 출처)를 쓴다.
- E05의 경고등 "꺼짐"은 시동 OFF→ON을 한 번 넘겼거나 10분 이상 켜져 있던 신호만 인정한다(센서 흔들림 방지). 켜고 바로 끄면 카드가 안 뜨므로 반드시 사이에 시동 OFF→ON을 넣는다. 오일 레벨 신호는 에뮬레이터가 지원하지 않아 설정 > 개발용 "차량 신호 흉내" 칩으로만 가능하다(이 칩은 켜자마자 인정된 신호로 둔다).
- 화면 문구는 2026-11-07 디자인 정리(커밋 8ffe0ef) 기준: 상태는 배너가 아니라 한 줄 글자, 경고는 알약 배지가 아니라 아이콘 + 빨간 값이다.
- 서드파티 헤즈업 알림은 에뮬레이터에 뜨지 않는다 → 알림 센터 + 홈 카드로 보여준다.
- 주행 중에는 시스템 차단 화면이 뜬다(DO 미선언). 주행 장면은 기어 전환만 짧게 보여준다.
- 지도 검색은 카카오 키가 없으면 OSM을 쓰는데 이 지역 정비소 데이터가 없다 → 데모 목적지 방식으로 찍는다.
